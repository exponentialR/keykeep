# Experimental preview feedback

No organised beta group or invitations are planned. Visitors may try the sample demo using fictional credentials and report ordinary usability bugs through GitHub issues. Security vulnerabilities should use the private reporting channel in SECURITY.md.

Useful checks for a volunteer's own isolated test deployment:

1. Generate and save a named fictional entry; lock and unlock.
2. Edit it, inspect history, delete it and restore it.
3. Export a backup, restore it, and change the master password.
4. Try keyboard navigation and a narrow viewport.
5. On a synthetic cloud deployment, try two-device offline edits and explicit conflict choices.

Never attach real vault backups, passwords, tokens, session cookies or screenshots of personal entries. Automated checks, voluntary feedback and independent security review are different forms of evidence. None establishes an audited production password manager.
